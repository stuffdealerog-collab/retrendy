# Blender-пайплайн СТРЕЛКИ

Всё строится кодом, внешних ассетов нет. Нужен Python 3.13 и модуль Blender:

```bash
pip install bpy==5.3.0 numpy pillow scipy      # + ffmpeg в PATH для сборки видео
```

То же самое работает внутри обычного Blender 5.x: `blender -b -P build_characters.py`.

| Скрипт | Что делает |
|---|---|
| `build_characters.py` | 4 аватара R6 + 24 анимации → `assets/strelka_characters.blend`, `assets/fbx/*.fbx`, превью |
| `build_trailer.py --frames 1 504` | собирает двор, постановку, камеры, свет и рендерит кадры (Cycles, CPU) |
| `build_trailer.py --save` | сохраняет сцену трейлера в `assets/strelka_trailer.blend` |
| `make_audio.py out.wav` | синтезирует трек трейлера (160 BPM) |
| `post.py <кадры> <wav> <mp4>` | цветокор, блум, импакт-кадры, телефон-HUD, титры, сборка mp4 |

Модули: `da_characters.py` (риг, геометрия, текстуры), `da_clips.py` (позы и клипы),
`da_world.py` (двор, колонка), `da_common.py` (материалы, туман, сборка мешей).

## Риг

Классическая иерархия R6, единицы: 1 стад = 0.3 м.

```
Root
└─ Torso            (корневой сустав: наклон, поворот, смещение таза)
   ├─ Head          шея        (0, 0, 1.20)
   ├─ Left Arm      плечо      (+0.30, 0, 1.05)
   ├─ Right Arm                (−0.30, 0, 1.05)
   ├─ Left Leg      бедро      (+0.15, 0, 0.60)
   └─ Right Leg                (−0.15, 0, 0.60)
```

Шесть мешей, каждый жёстко привязан к одноимённой кости. Персонаж смотрит в −Y, левая сторона +X.
Все кости в покое направлены вверх — у них общий базис, поэтому позы пишутся в осях персонажа.

## Анимации

Клипы размечены **в долях такта**, а не в секундах. Экспорт: 30 fps при 150 BPM = 12 кадров на долю.
В Roblox: `track:AdjustSpeed(bpm / 150)`.

| Клип | Доли | Ключевой момент |
|---|---|---|
| `SK_Idle`, `SK_Guard` | 4 / 2, цикл | кивок / подскок в каждую долю |
| `SK_Walk`, `SK_Run`, `SK_Sprint`, `SK_CarryRun` | 2, цикл | один шаг на долю |
| `SK_Dvoika` | 2 | джеб на 0.5, кросс на **1.0** |
| `SK_Haymaker` | 2.5 | замах 0–1, попадание на **1.0** |
| `SK_PushKick` | 2.5 | попадание на **1.0** |
| `SK_Slip`, `SK_Block` | 1.5 | пик на **0.5** |
| `SK_Hit`, `SK_Stagger` | 1 / 2.5 | реакции на лёгкий и тяжёлый удар |
| `SK_Knockdown`, `SK_GetUp` | 3 / 2 | падение за 1 долю |
| `SK_FlyKick` | 2.5 | толчок на 0, пятка на **1.0** |
| `SK_Slide`, `SK_PickUp`, `SK_Victory` | 3 / 2 / 4 | |
| `SK_EmoteTwoStep` | 4, цикл | танец лобби |
| `SK_PoseShoulder / Sit / Lean / Squat` | поза | для превью и меню |

Новая поза — одна строка в `da_clips.py`:

```python
Q(hip=(0, 0.26, -0.03), t=(18, 0, 52), h=(8, 0, -50), la=(34, 18, 30), ra=(94, -6, 0), ll=(32, 5), rl=(-34, 8, 30))
#  таз (влево, вперёд, вверх)   торс (наклон, крен, поворот)   руки (вперёд, в сторону, скрутка)   ноги (вперёд, в сторону)
```

Опорная нога держится на земле автоматически (`ground=True`).

## Импорт в Roblox Studio

Не проверялось в Studio — ниже ожидаемый путь, а не подтверждённый.

1. **Персонаж**: Avatar → *3D Importer* → `assets/fbx/<ИМЯ>.fbx`. Rig type — *Custom* (кости) или собрать R6 из шести `MeshPart` с `Motor6D` по именам частей. Масштаб: 1 м = 3.33 стада.
2. **Анимации**: открыть R6-риг в *Animation Editor* → *Import → From FBX Animation*. В FBX каждый клип лежит отдельным дублем `SK_*`; имена суставов совпадают с R6 (`Torso`, `Head`, `Left Arm`…).
3. **Аватары игроков**: в игре свои меши не нужны — игрок приходит в собственном аватаре (Game Settings → Avatar → R6), а эти клипы проигрываются на нём.
4. Розовое свечение (кольца колонки, акценты одежды) в Roblox делается материалом `Neon` или `SurfaceAppearance`; карта `*_emit.png` показывает, где именно.
