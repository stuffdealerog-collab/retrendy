# creative-studio

Плагин Claude Code: универсальный креативный движок, который анализирует тренды
и генерирует **неусреднённые** идеи. Плагин не привязан к человеку, бренду или
рынку: вкус и идентичность подключаются через файлы, которые вы заполняете
сами. Пока они пусты, студия работает нейтрально и ничего за вас не придумывает.

Главный принцип: языковые модели сходятся к типичному и повторяют себя между
запусками, поэтому оригинальность здесь обеспечивается **механикой**, а не
просьбой «будь креативным»:

| Механизм | Где живёт |
|---|---|
| Verbalized sampling: варианты с вероятностями, в работу идёт только хвост (p < 0.15), а «голова» уходит в фильтр как запретная зона | `skills/diverge`, агенты `diverger` и `outsider` |
| Цепочка «черновик → что тут предсказуемо → смелее и конкретнее» для каждого концепта | `skills/diverge`, шаг 3 |
| 4 параллельные ветки с **разными** стратегиями мышления; карточки (TRIZ, SCAMPER, oblique, ограничения, чужие домены) тянет скрипт со случайным seed, а не модель | `config/studio.json → branches`, `cstudio init` |
| Внешняя память: лог всех генераций, банк клише, «пре-мортем» предсказуемых ответов на конкретный бриф | `generation-log.jsonl`, `domains/*/cliche-bank.md`, агент `cliche-hunter` |
| Автоматический фильтр новизны по многоязычным эмбеддингам (клише, предсказуемое, повторы прошлых прогонов, коллажи из клише, дубли внутри пула) с причиной для каждого отсева | `scripts/novelty_check.py` |
| Критик отделён от генераторов: рубрика из 5 критериев, каждая оценка с дословной цитатой (скрипт проверяет, что цитата есть в тексте), затем слепой попарный турнир | агент `creative-director`, `skills/critique`, `cstudio validate / pairs / rank` |

Персоны «гениев» и температура как рычаг креативности не используются.

## Пайплайн `/creative-studio:create`

```
бриф ─► cstudio init (run, seed, карточки веток)
     ├─► trend-analyst  (MCP trend-sources → web search → кэш снимков → evergreen)   ┐ параллельно
     └─► cliche-hunter  MODE baseline: 15–25 предсказуемых ответов на ЭТОТ бриф        ┘
     ─► cstudio context (бриф + идентичность или нейтральный режим + тренды/инсайты
                         + «не строить на этом» + «уже было в прошлых прогонах»)
     ─► 4 ветки параллельно: diverger A (SCAMPER+TRIZ) · diverger B (oblique+ограничения)
                             · diverger C (контр-тренд, только хвост) · outsider D (чужой домен, blending)
        └─ каждая: голова распределения → хвост с p → эскалация → самофильтр → ```cs:concepts```
        └─ хук SubagentStop пишет концепты в лог (status=candidate)
     ─► cstudio novelty  (эмбеддинги: банк клише + baseline + последние N из лога + дубли)
     ─► cliche-hunter MODE review (структурные клише, пропущенные эмбеддингами;
                                   предложения в банк) ─► cstudio survivors (+ refill-ветка, если выжило мало)
     ─► creative-director (рубрика с цитатами) ‖ audience-proxy (реакция аудитории из брифа)
     ─► cstudio validate (проверка цитат) ─► cstudio pairs ─► свежий creative-director: слепой турнир
     ─► cstudio rank (рубрика 50 % + доля побед 50 %, MMR-разнообразие финалистов)
     ─► editor: каждый финалист в версиях safe / bold / director's cut
     ─► cstudio report ─► вопрос пользователю «какой и почему»
     ─► ответ ─► ```cs:selection``` ─► хук Stop: статусы в логе + запись в taste-profile
```

Типичный прогон: около 32 концептов на входе, 3 финалиста × 3 версии на
выходе, 10 сабагентов. Время 15–30 минут в зависимости от модели и сети.

## Установка

Требования: Claude Code ≥ 2.1, `python3` ≥ 3.9. Рекомендуется
[`uv`](https://docs.astral.sh/uv/): с ним фильтр новизны сам ставит `fastembed`
при первом запуске. Без `uv` выполните `pip install fastembed numpy`. Без
обоих фильтр работает в деградированном лексическом режиме.

Через локальный маркетплейс (репозиторий сам является маркетплейсом
`retrendy`):

```bash
claude plugin marketplace add /path/to/retrendy          # или ./retrendy
claude plugin install creative-studio@retrendy            # --scope project, чтобы включить только в одном проекте
claude plugin list                                        # creative-studio@retrendy  ✔ enabled
```

То же внутри сессии: `/plugin marketplace add /path/to/retrendy`, затем
`/plugin install creative-studio@retrendy`.

Для разработки без установки: `claude --plugin-dir /path/to/retrendy/plugins/creative-studio`.

Первый `/create` скачивает модель эмбеддингов (около 1 ГБ, один раз) в
`<state>/cache/models`. Можно заранее: `cstudio novelty --warmup` внутри сессии
или `python3 plugins/creative-studio/scripts/novelty_check.py --warmup`.

Проверка:

```bash
claude plugin validate plugins/creative-studio --strict
python3 -m unittest discover -s plugins/creative-studio/tests -v
```

## Переменные окружения

Ни одна не обязательна. Задайте их в окружении до запуска `claude` или в
`<state>/.env` (формат как в `.env.example`).

| Переменная | Что включает |
|---|---|
| `YOUTUBE_API_KEY` | `youtube_trending`: популярное на YouTube по региону и категории |
| `APIFY_TOKEN` | `social_search`: хэштеги TikTok и Instagram через Apify, только чтение |
| `APIFY_TIKTOK_ACTOR`, `APIFY_INSTAGRAM_ACTOR` | другие акторы Apify |
| `CREATIVE_STUDIO_HOME` | своя папка состояния, например git-репозиторий с брендом и логом |
| `CREATIVE_STUDIO_BRAND` | какой файл из `<state>/brand/` активен |
| `HF_TOKEN` | только повышает лимиты скачивания модели |

Без ключей работают Google Trends (RSS «Trending now»), самые читаемые статьи
Wikipedia, Hacker News и публичные Telegram-каналы через `t.me/s/…`
(только чтение). Дальше идёт WebSearch, потом кэш снимков трендов не старше
14 дней, потом evergreen-режим. Пайплайн не падает ни на одном уровне.

## Пример

```
/creative-studio:create Домен: тексты песен. Цель: песня о первом месяце в новом городе,
когда ты ещё никого там не знаешь. Аудитория: не задана. Ограничения: русский язык;
припев не длиннее 4 строк. Табу: реальные бренды и реальные люди.
```

В ответ приходит отчёт:

- режим (нейтральный или идентичность, live / cached / evergreen тренды, бэкенд эмбеддингов);
- воронка (сгенерировано → после фильтра → после cliche-hunter → оценено → турнир → финалисты);
- что выброшено и почему (с косинусом и номером клише);
- таблица финалистов;
- для каждого финалиста версии safe / bold / director's cut;
- вопрос «какой и почему».

Ответ в свободной форме, например:

```
F2, смелую. Нравится, что одиночество показано через бытовую процедуру, без слова «одиноко».
```

Хук Stop записывает выбор в лог (`selected` / `rejected` с причиной) и в журнал
`taste-profile.md`.

Headless: `claude -p "/creative-studio:create <бриф>"`, а выбор следующим
вызовом: `claude -p --resume <session-id> "F2 bold, потому что …"`.

Другие skills: `/creative-studio:trend-radar <тема>`, `/creative-studio:insight`,
`/creative-studio:diverge <идея>` (быстрые хвостовые вариации без пайплайна),
`/creative-studio:critique`, `/creative-studio:converge`,
`/creative-studio:brand-memory`. Если имя не занято другим плагином, работает и
короткий вызов `/create`.

## Где лежат данные

Состояние меняется, поэтому хранится вне папки плагина: при обновлении
плагин копируется в новую версионную папку, и записанное туда пропало бы.
Порядок поиска:

1. `CREATIVE_STUDIO_HOME`;
2. `<проект>/.creative-studio/`, если такая папка есть (отдельный бренд и лог на проект);
3. `${CLAUDE_PLUGIN_DATA}` = `~/.claude/plugins/data/creative-studio-<маркетплейс>/` (переживает обновления);
4. `<плагин>/data/` (только при разработке).

Путь показывает `cstudio identity` или `cstudio log stats`. Внутри:

```
generation-log.jsonl   все концепты всех прогонов
taste-profile.md       ваш вкус (сверху) + журнал выборов (снизу, пишет хук)
brand/<name>.md        бренды; активный выбирается автоматически или через CREATIVE_STUDIO_BRAND / config.json
cliche-bank/<domain>.md  ваши добавления к банку клише
trend-snapshots/       снимки трендов по датам (для офлайн-режима)
runs/<run_id>/         всё о прогоне: brief, draw (seed и карточки), artifacts, pool, novelty, scores, ranking, report
cache/                 модель и кэш эмбеддингов (SQLite)
config.json            ваши переопределения config/studio.json
```

## Бренд и taste-profile

**Taste-profile** — ваш личный вкус. Откройте `<state>/taste-profile.md` и
заполните верхние разделы своими словами: что цените, что раздражает,
эталонные работы, риск по умолчанию. Строки с `>` считаются подсказками.
Ниже маркера `<!-- cs:auto -->` хук после каждого выбора дописывает запись:
что выбрано, какая версия, какая стратегия, почему, что отклонено. Там же он
пересчитывает «выведенные сигналы»: доли safe / bold / director, выигрышные
стратегии, среднюю новизну выбранного. `/creative-studio:brand-memory distil`
предложит превратить повторяющиеся причины в явные принципы.

**Бренд**: `/creative-studio:brand-memory new-brand <name>` копирует
`skills/brand-memory/brand/_template.md` в `<state>/brand/<name>.md` и проводит
интервью по разделам. Вручную: `cstudio identity --init-brand <name>`,
отредактировать файл, затем `cstudio identity --use-brand <name>`.

Хук SessionStart подгружает в контекст бренд и вкус **только если в них есть
содержание, написанное человеком** (до 6000 символов). Пустые шаблоны дают
одну строку «neutral mode»: ни один агент не придумывает голос, аудиторию или
«фирменный стиль».

## Как добавить домен

1. Скопируйте `domains/_template/` в `domains/<slug>/`.
2. В `domain.md` опишите, что такое концепт в этом домене (поля и примеры
   плохо/хорошо), где обычно живёт оригинальность, сигналы трендов с
   seed-запросами, поля версий редактора, табу по умолчанию. Во frontmatter:
   `status: stub|full`, `line_check: true` (для текстовых доменов со строками),
   `outsider_exclude: [...]` (слова, при которых «чужой» домен слишком близок).
3. В `craft.md` напишите правила крафта и якоря 1–5 для критерия craft.
4. В `cliche-bank.md` наберите 60–100 клише.
5. Проверьте: `cstudio domains`, затем
   `python3 scripts/novelty_check.py --domain <slug> --text "заведомое клише"`.

Ядро доменно-независимо: незнакомый домен идёт как `generic`, а
cliche-hunter всё равно строит baseline предсказуемых ответов под бриф.

## Как пополнять банк клише

Формат строки: `- **XX-NNN** {необязательные теги} русская формулировка / english phrasing`.
Варианты через ` / ` эмбеддятся отдельно, побеждает максимум. ID не
перенумеровывать. Тег `{rhyme}` означает лексическую проверку окончаний строк
сэмпла (предупреждение, не отсев).

- **Свои добавления, которые переживут обновления плагина:**
  `cstudio bank-add --domain lyrics --category "Story arcs" --text "… / …"`.
  Они попадают в `<state>/cliche-bank/lyrics.md` с ID вида `LYL-001`.
- **Предложения cliche-hunter.** Каждый прогон он предлагает до 5 новых
  клише. Они видны в отчёте и в `runs/<id>/bank-proposals.md`, а добавляются
  только с вашего согласия.
- **В сам плагин** (для всех пользователей): дописывать в конец раздела
  `domains/<d>/cliche-bank.md` со следующим свободным номером.

Хорошее клише — конкретный ход («сжечь фотографии бывшего, чтобы забыть»), а
не тема («расставание»). Тема заставит фильтр отсеивать всё подряд.

## Фильтр новизны

`scripts/novelty_check.py`, через CLI: `cstudio novelty --run <id>`.

**Модель: `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`** через
`fastembed` (ONNX, без PyTorch).

- обучена именно на задачу «перефраз или нет» и мультиязычна (50+ языков, общее
  пространство для RU и EN);
- косинус у неё хорошо разнесён, поэтому порог 0.8 осмыслен. У e5 и bge
  сходства сжаты в диапазон 0.7–0.9, там 0.8 ничего не значит;
- на замерах она ловит перефразы на уровне концептов, которые пропускает
  `paraphrase-multilingual-MiniLM-L12-v2` (0.82 против 0.70 на «сжечь фото
  бывшего», 0.83 против 0.68 на «ночная поездка по пустому городу»), при этом
  несвязанные пары остаются ниже 0.4;
- MiniLM доступна как `--lite` (220 МБ вместо 1 ГБ).

Если не загрузились ни fastembed, ни sentence-transformers, включается
лексический режим (символьные 3-граммы, `"degraded": true`). Он ловит только
почти дословные повторы.

**Что проверяется:**

- **грани концепта** отдельно: весь текст, ядро (название + логлайн),
  логлайн, каждое предложение. Длинное описание размывает косинус с короткой
  фразой клише, поэтому берётся максимум по граням;
- **против банка клише** домена (+ ваши добавления), **baseline** прогона
  (пре-мортем cliche-hunter + «головы» распределений генераторов),
  **последних N = 200 записей лога** того же домена из прошлых прогонов;
- **коллаж клише**: одно клише ≥ 0.70 и второе ≥ 0.62 одновременно, то есть
  два полуклише, склеенные в «идею»;
- **дубли внутри пула** (max по полному тексту и ядру ≥ 0.8). Остаётся
  вариант с меньшей вербализованной вероятностью, то есть более хвостовой;
- **строки сэмпла** против банка (≥ 0.8) и рифмы-клише на концах строк:
  предупреждения для редактора, не отсев.

Пороги лежат в `config/studio.json → novelty`, переопределяются в
`<state>/config.json`:
- `threshold` 0.8 — жёсткий отсев;
- `soft_threshold` 0.7 — мягкий флаг: концепт идёт к cliche-hunter первым;
- `collage_second_threshold` 0.62;
- `pool_duplicate_threshold` 0.8;
- `line_threshold` 0.8;
- `history_window` 200.

Кэш эмбеддингов лежит в `<state>/cache/embeddings.sqlite`, повторные тексты
не пересчитываются.

**Калибровка на фикстурах** (`tests/fixtures/`, 17 концептов, бриф про
одиночество в большом городе):

- свежие концепты дают максимум 0.63–0.68 к любой референции;
- явные перефразы клише 0.81–0.96: отсеяны с номером клише;
- коллажи 0.73 + второе совпадение: отсеяны;
- повторы прошлых прогонов 0.86–0.93: отсеяны;
- предсказуемое 0.84: отсеяно;
- дубль внутри пула 0.97: схлопнут.

Мягкие перефразы на 0.70–0.73 («сжигает письма», «doomscroll») получают
мягкий флаг и уходят на суд cliche-hunter. Для более строгого фильтра
поставьте `threshold: 0.75`.

Пример причины отсева:

```json
{"id": "c_…", "reason_code": "cliche", "match": {"source": "bank", "ref_id": "LY-066", "facet": "core", "sim": 0.959},
 "reason": "Its core is too close to cliché LY-066: «Пьяный звонок бывшему в три часа ночи / drunk dialling…» (cos 0.96 ≥ 0.80)"}
```

`reason_code`: `cliche`, `cliche_collage`, `predictable`, `repeat`, `duplicate`.

## Формат generation-log.jsonl

Одна строка — один концепт. Запись обновляется по `id` под файловой
блокировкой. Статус не откатывается назад.

```json
{"id": "c_5e1f0a9b2c", "ts": "2026-10-08T16:40:00Z", "run_id": "r_20261008_164000_ab12", "domain": "lyrics",
 "brief": "цель | audience: … | constraints: … | taboos: …",
 "title": "…", "logline": "…", "text": "…", "sample": "…",
 "strategy": "structural", "operator": "T13 The other way round", "branch": "A", "agent": "creative-studio:diverger", "p": 0.06,
 "scores": {"novelty_embed": 0.41, "novelty": 4, "surprise": 3, "usefulness": 4, "brief_fit": 4, "craft": 3,
            "rubric_total": 0.66, "tournament_winrate": 0.8, "final": 0.73},
 "status": "selected", "reason": "user: …", "version": "bold"}
```

Статусы:

- `candidate` — сгенерирован;
- `filtered` (отфильтрован) — фильтром новизны или cliche-hunter;
- `rejected` (отклонён) — ниже отсечки, проиграл турнир или не выбран пользователем;
- `finalist`;
- `selected` (выбран).

Кто пишет:

- **SubagentStop** — кандидатов из блоков ```` ```cs:concepts ````;
- **Stop** — сводит статусы, оценки и причины из файлов прогона и
  применяет ```` ```cs:selection ````.

Если хуки отключены, то же делают вручную: `cstudio log ingest`,
`cstudio log reconcile`, `cstudio log select`.

| Нет | Что происходит |
|---|---|
| ключей YouTube / Apify | инструменты отвечают `configured: false`, используются бесключевые источники |
| сети или MCP-сервера | WebSearch → снимки трендов ≤ 14 дней → evergreen (режим указан в отчёте) |
| `uv` и `fastembed` | лексический фильтр, `"degraded": true` в отчёте |
| бренда и taste-profile | нейтральный режим |
| полного пакета домена | ядро + seed-банк заготовки или режим `generic` |
| хуков | ручные команды `cstudio log …` (skill create это знает) |

## Допущения

- **Домен для MVP — тексты песен.**
  - Артефакт текстовый: критик может цитировать реальные строки, фильтр
    проверяет и концепт, и строки, и рифмы.
  - Клише в песнях стабильны десятилетиями и узнаваемы сразу, поэтому
    отсев с номером клише наглядно доказывает работу фильтра.
  - Концепты коротких видео описывают нетекстовый артефакт, а их клише
    устаревают за месяцы.
- **`research.md` в репозитории не было.** Архитектура построена по ТЗ.
- **Состояние хранится в `${CLAUDE_PLUGIN_DATA}`, а не в `data/` плагина**,
  потому что папка плагина заменяется при обновлении. `data/` содержит
  только шаблоны первого запуска.
- **Домены — пакеты данных в `domains/`, а не skills.** Skills обнаруживаются
  на одном уровне, и доменный пакет не должен срабатывать сам по себе.
- **Добавлен агент `diverger`** (генератор с параметром-стратегией): в
  исходном списке не было агента, который генерирует. Критик никогда не
  генерирует.
- **Oblique Strategies — оригинальные подсказки в духе метода.** Тексты карт
  Эно и Шмидта защищены авторским правом.
- **Google Trends подключён через официальный RSS «Trending now».**
  Неофициальный explore-API без cookies отвечает 429, а `pytrends` в архиве.
  Reddit не подключён: публичные JSON отвечают 403 без OAuth.
- **Telegram — только публичные каналы через веб-превью** `t.me/s/…`.
  Приватные каналы потребовали бы API ID / hash и сессию, а это уже не «только
  чтение без ключей».
- **Язык.** Промпты агентов на английском (модели это всё равно), выход на
  языке брифа. Пользовательские шаблоны (вкус, бренд) и README — на русском.
- **Аудитория по умолчанию.** Если она не задана, audience-proxy
  симулирует широкую взрослую аудиторию рынка брифа и явно это помечает.
- **Модели.** Все агенты наследуют модель сессии (`model` не задан).
  Удешевить можно, поставив `model: sonnet` у trend-analyst и audience-proxy.
- **Веса рубрики:**
  - новизна 0.25, неожиданность 0.2, полезность 0.15, соответствие брифу 0.2, крафт 0.2;
  - эмбеддинговая новизна подмешивается на 30 %, аудитория на 10 %;
  - финал = 50 % рубрика + 50 % доля побед в турнире.
- **Python stdlib в хуках и MCP-сервере**, чтобы они работали на голом
  `python3`. Зависимости есть только у фильтра новизны, и они ставятся сами
  через `uv`.

## Ограничения и известные проблемы

- **Свободные перефразы около 0.75 не ловятся при пороге 0.8.** Пример —
  «ода курьеру на девятый этаж» против «гимна курьеру без лифта». Их ловит
  cliche-hunter или критик, либо можно понизить `pool_duplicate_threshold`
  до 0.75: на фикстурах разные идеи одного брифа не превышают 0.64.
- **Первый прогон скачивает модель на 1 ГБ.** Без сети и без кэша фильтр
  уходит в лексический режим.
- **В headless-режиме (`-p`) AskUserQuestion недоступен.** Вопрос задаётся
  текстом, ответ приходит следующим сообщением (`--resume`).
- **Нет защиты от параллельных `/create` в одной папке состояния:** указатель
  `runs/LATEST` один. Блоки агентов несут `run_id`, так что артефакты не
  перепутаются, но `cstudio … --run` без id возьмёт последний прогон.
