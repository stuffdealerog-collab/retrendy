Плагин установлен через локальный маркетплейс (`claude plugin marketplace add`
+ `claude plugin install creative-studio@retrendy --scope project`).
Запускался headless: `claude -p "/creative-studio:create <бриф>"`, выбор
отправлялся следующим вызовом `--resume`.

## Что нашлось и было исправлено по ходу

1. **Ложные коллажи клише в прогоне 1.**
   - Правило коллажа сработало 4 раза на структурных клише («заглавие-хук»,
     «перекличка он сказал / она сказала») через предложения, описывающие
     механику припева.
   - Исправление: тег `{structure}` (эти клише судит cliche-hunter, а не
     эмбеддинги); коллаж считается только по граням идеи (весь текст,
     ядро, логлайн).
   - Перепроверка того же пула: 0 ложных срабатываний
     (`run1-novelty-recheck-after-fix.json`).
2. **Дубли ниже порога.**
   - Два «Контактных лица» из разных веток имели косинус 0.77 и не
     схлопнулись при пороге 0.8. Их поймал cliche-hunter.
   - Теперь пары 0.75–0.80 явно передаются ему списком. В прогоне 2 он
     по этому списку снял 2 дубля: «Мама/Папа Бублика» и две вариации
     соседок на лавке.
3. **Блоки агентов.**
   - Турнирный судья в прогоне 1 оформил блок как ```` ```json ````.
   - Генератор ветки C в прогоне 2 оставил висячую запятую в JSON.
   - Оба раза оркестратор сам нашёл пропуск через `cstudio status` и
     догрузил артефакт через `cstudio log ingest` (путь восстановления
     сработал как задуман).
   - После этого парсер принимает такие блоки сам: распознаёт вид по
     сигнатуре и прощает висячие запятые.
4. **Финалисты с одним ходом.** Разнообразие финалистов теперь считается по
   матрице эмбеддингов из фильтра, а не по метке стратегии. В прогоне 1 два
   финалиста из трёх были про кассовые чеки.
